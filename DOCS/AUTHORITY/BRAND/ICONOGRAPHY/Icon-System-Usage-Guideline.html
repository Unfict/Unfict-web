Icon SystemUsage Guideline · Draft
UNFICT ICONOGRAPHY · A–J · 123 ASSETS

One icon system.
One implementation pattern.

A self-contained reference for shipping the Unfict icon bundle as lightweight CSS masks on a 24 × 24 SVG grid, with scalable sizing and currentColor inheritance. Dummy glyphs are used in this draft; IDs, collection structure, brand treatment, and implementation rules are production-oriented.

02 · Implementation model

CSS mask for monochrome icons; SVG for governed two-tone assets

A single CSS mask is inherently one-color. That is ideal for functional icons and monochrome variants. Domain icons that intentionally combine Deep Ink and Unfict Blue should remain SVG or use a deliberate layered implementation.

24 × 24 source geometry

Keep masters on the canonical 24 × 24 viewBox. Rendering size is controlled by CSS, not by changing the source coordinate system.

Inherited color

The mask is painted with background-color: currentColor, so text, link, button, and theme color flow into the icon automatically.

Stable glyph geometry

Hover, active, disabled, focus, and selected states should normally change tokens or containers rather than redraw the icon.

03 · Base CSS

One base class, one modifier per governed icon ID

In production, move registrations into cacheable collection-level stylesheets. This guide inlines them only so the HTML remains completely self-contained.

Base classCSS
.uf-icon {
  display: inline-block;
  width: 1em;
  height: 1em;
  font-size: 24px;
  background-color: currentColor;
  -webkit-mask-image: var(--uf-icon-mask);
  mask-image: var(--uf-icon-mask);
  -webkit-mask-size: contain;
  mask-size: contain;
  -webkit-mask-repeat: no-repeat;
  mask-repeat: no-repeat;
  -webkit-mask-position: center;
  mask-position: center;
  vertical-align: -0.125em;
}

.uf-icon-home {
  --uf-icon-mask: url("data:image/svg+xml,...24x24 SVG...");
}
HTML usageAccessibility
<!-- Decorative -->
<span class="uf-icon uf-icon-home" aria-hidden="true"></span>

<!-- Icon button -->
<button aria-label="Open primary navigation">
  <span class="uf-icon uf-icon-menu" aria-hidden="true"></span>
</button>

<!-- Unfamiliar domain icon -->
<span><span class="uf-icon uf-icon-resolver" aria-hidden="true"></span> Resolver</span>
Performance: CSS masks avoid icon-font layout shift and support a single cached stylesheet. For 123 assets, split the production CSS by collection or usage tier so each surface downloads only what it uses.

06 · Accessibility contract

Glyphs support meaning; they do not replace labels

Decorative icons should be hidden from the accessibility tree. Icon buttons need contextual accessible names. Unfamiliar domain icons should be paired with visible text on first or primary use.

Decorative

Use aria-hidden="true" when the icon repeats meaning already present in adjacent text.

Interactive

Put the accessible name on the interactive control, e.g. “Copy Digital Link URI,” rather than on the glyph itself.

Status

Never communicate success, failure, availability, authority, or verification through color alone. Pair shape with text or explicit state labeling.
